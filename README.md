# gavho.github.io

Personal portfolio for Gavin Ho: geospatial analyst and aviation planner.

A static site (`index.html` + `styles.css`) with no build step. The visual system is adapted from the Linear `DESIGN.md` in [awesome-design-md](https://github.com/VoltAgent/awesome-design-md).

Preview locally by opening `index.html`, or run `python -m http.server` and visit http://localhost:8000.
