# gavho.github.io

Personal portfolio for Gavin Ho: GIS analyst and developer, and aviation planner.

A static site (`index.html` + `styles.css` + `assets/`) with no build step. The visual system is adapted from the Linear `DESIGN.md` in [awesome-design-md](https://github.com/VoltAgent/awesome-design-md).

- `assets/img/ord-aerial.jpg`, `assets/img/mdw-aerial.jpg`: O'Hare and Midway orthoimagery from USGS The National Map (public domain), converted to grayscale.
- `assets/img/flood-*.jpg`: figures from the Jasper County Airport flood risk research.

Preview locally by opening `index.html`, or run `python -m http.server` and visit http://localhost:8000.
